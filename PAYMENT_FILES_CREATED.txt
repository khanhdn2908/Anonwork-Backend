API ENDPOINTS
================================================================================

1. POST /api/v1/payments/create-order
   - Create order and get payment link
   - Authorization: Required (JWT)
   - Request: { "planId": "uuid" }
   - Response: Order details with payment link

2. GET /api/v1/payments/orders/{orderId}
   - Get order status
   - Authorization: Required (JWT)
   - Response: Order details

3. POST /api/v1/payments/webhook
   - Handle Sepay webhook
   - Authorization: Not required (signature verification)
   - Request: Webhook data from Sepay
   - Response: { "success": true }

4. POST /api/v1/payments/subscriptions/{subscriptionId}/renew
   - Renew subscription
   - Authorization: Required (JWT)
   - Response: { "success": true }
